# 🥔 감자(Gamza) - 포근한 우리 동네 중고장터

따뜻한 브라운 & 버터 옐로우 감성의 우리 동네 중고 직거래 웹 서비스입니다.  
프레임워크 없이 순수 **HTML / CSS / Vanilla JavaScript**로 구현되었으며, **Supabase(Auth & PostgreSQL)**와 실시간으로 연동됩니다.

---

## ✨ 주요 기능

1. **화면 1 — 상품 목록 및 실시간 필터 (`screen1.js`, `screen1.css`)**
   - 카테고리별 캡슐 필터 (`전체`, `디지털기기`, `가구/인테리어`, `의류`, `생활가전`, `도서/티켓`, `기타`)
   - 실시간 검색어 필터링 (상품명, 동네, 설명, 판매자 닉네임)
   - `거래 가능만 보기` 토글 스위치 및 판매 상태 배지 (`판매중`, `예약중`, `거래 완료`)
2. **화면 2 — 상품 상세 모달 (`screen2.js`, `screen2.css`)**
   - 상품 상세 정보 및 판매자 프로필 표시
   - 관심 상품(🤍/❤️) 찜하기 토글 (Supabase `wishes` 테이블 및 `localStorage` 연동)
   - **작성자 전용 관리 패널**: 게시글 작성자 본인일 경우 모달 내에서 즉시 `판매중` / `거래 완료` 상태 전환, 게시글 **수정** 및 **삭제** 가능
3. **화면 3 — 내 물건 팔기 / 글쓰기 & 수정 (`screen3.js`, `screen3.css`)**
   - 기기 이미지 파일 업로드(Data URL), 외부 이미지 URL 입력, 감자 테마 기본 일러스트 샘플 프리셋 지원
   - 가격 천 단위 콤마 자동 포맷팅, 거래 희망 동네 퀵 칩, 글자 수 카운터 제공
4. **회원가입 / 로그인 인증 (`app.js`, `index.html`, `style.css`)**
   - Supabase Auth 기반 이메일·비밀번호 회원가입(닉네임 설정) 및 로그인/로그아웃
   - 비로그인 상태에서 글쓰기 클릭 시 로그인 안내 후 글쓰기 화면으로 자동 연결

---

## 🗂️ 파일 구조

```text
Gamza/
├── index.html       # 메인 엔트리 HTML (통합 레이아웃 및 로그인/회원가입 모달)
├── style.css        # 공통 디자인 시스템(CSS 변수) 및 인증 모달 스타일
├── app.js           # 통합 앱 컨트롤러 및 Supabase(Auth, products, profiles, wishes) 연동
├── screen1.css      # [화면 1] 상품 목록 및 헤더/필터 스타일
├── screen1.js       # [화면 1] 상품 목록 렌더링 및 검색/필터 로직
├── screen2.css      # [화면 2] 상품 상세 모달 스타일
├── screen2.js      # [화면 2] 상품 상세 모달 및 작성자 전용 관리 로직
├── screen3.css      # [화면 3] 글쓰기/수정 폼 스타일
├── screen3.js       # [화면 3] 글쓰기/수정 폼 로직
└── .env.example     # 환경 변수 예시 파일
```

## 🚀 실행 방법

별도의 빌드 과정 없이 정적 웹 서버나 브라우저에서 `index.html`을 열어 바로 실행할 수 있습니다.

```bash
# VS Code Live Server 또는 간단한 로컬 서버로 실행
npx serve .
```
